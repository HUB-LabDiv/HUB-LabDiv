• Experiência Desktop Nativa (Windows):
  - Atalho direto na bandeja do sistema (System Tray) para pausas visuais (regra 20-20-20), hidratação e modo hiperfoco.
  - Notificações nativas do Windows para compromissos acadêmicos e alertas da comunidade.
  - Login seguro via navegador externo (OAuth RFC 8252) com protocolo hublabdiv://.
  - Armazenamento seguro de credenciais e suporte a espelhamento de pastas.

Projeto de software livre desenvolvido no IFUSP sob licença GNU AGPLv3.

### Description (up to 10,000 characters)
```text
HUB LabDiv is the official science communication platform of the Science Outreach Laboratory (LabDiv) at the Institute of Physics of the University of São Paulo (IFUSP), now available as a native Windows desktop application.

Built for students, researchers, educators, and science enthusiasts, HUB LabDiv combines science outreach, academic life, and productivity tools in a fast desktop experience with Windows System Tray integration and automatic Light/Dark theme support.

KEY FEATURES:
• Science Feed & Archive: Browse outreach articles, posters, videos, community logs, and educational materials created by IFUSP students and researchers.
• IFUSP Knowledge Base & Wiki: Explore campus spaces, student organizations, scholarships, research opportunities, and an interactive scientific glossary.
• Academic Tools (USP Students): Build your weekly class timetable, track absences, plan study blocks, follow learning trails, and discover academic software.
• Academic Match & Networking: Connect with classmates, mentors, undergraduate research labs, and scientific initiatives.
• Native Windows Desktop Experience:
  - System Tray quick actions for study wellness (20-20-20 eye rest reminders, hydration, and hyperfocus mode).
  - Native Windows notifications for academic events and community updates.
  - Secure external-browser OAuth login (RFC 8252 loopback) with hublabdiv:// deep linking.
  - Hardware-backed credential storage and folder sync support.

Open-source software developed at IFUSP under the GNU AGPLv3 license.
```
